# AI Coding Evaluation Lab

An independent laboratory for evaluating AI coding assistance with reproducible tasks, explicit acceptance criteria, and human review.

## Current status

Repository foundation only. The repository currently contains governance and documentation files, with no application implementation or validated feature claims.

## Scope

Planned work includes synthetic evaluation tasks, structured observations, and validation evidence. Results will describe what was actually run and observed; no benchmark scores or assistant capabilities are claimed by this foundation.

## Working principles

- Human-led decisions, explicit acceptance criteria, AI assistance where useful, and independent review.
- Evidence-based validation with actual commands and results; test-driven verification where applicable.
- PASS / HOLD / FAIL gate decisions before a change is proposed for merge.

Evaluation datasets must be synthetic or explicitly cleared for public release. Preserve prompts, model or tool versions, task inputs, acceptance criteria, and observed outputs when publishing an evaluation.

## Security and independence

This project is independent of commercial RQS work. Never use proprietary RQS Studio code, production systems, real customer data, or credentials. Use synthetic data and independent implementations. See `SECURITY.md` and `AGENTS.md`.
